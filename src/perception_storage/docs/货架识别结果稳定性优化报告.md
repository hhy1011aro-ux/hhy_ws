# 货架识别结果稳定性优化报告

> 版本：V1.4  
> 日期：2026-09-24  
> ROS包：`perception_storage`  
> 对比原则：始终以初始问题bag为基线，与当前最新优化bag对比；后续优化时仅替换最新bag及其分析结果。

## 1. 背景与目标

`perception_storage` 使用Livox激光点云识别货架标签及辅助边线，输出货架中心位置和航向角。输入、处理中间结果和最终结果话题分别为：

```text
输入点云：/livox/lidar_front
中间点云：/perception/capture/points
识别结果：/hecbot_perception/storage_result
```

初始测试中主要存在以下问题(livox_frame_front 坐标系)：

- 部分输入帧没有识别结果，输出不连续。
- 航向角存在高频往返变化，部分相邻帧跳变超过 `2°`。
- 货架中心的x方向存在毫米至厘米级帧间波动。
- 算法输出点包含固定距离补偿，必须与Gazebo模型原点统一参考点后才能评价中心精度。

本次工作的目标是：

1. 判断是否每一输入帧都有结果，并定位无结果发生的处理阶段。
2. 去除算法输出中的固定距离补偿后，与仿真货架真实中心比较，评价x、y和yaw精度。
3. 分别评价x、y和yaw的相邻帧跳变，区分正常连续帧与漏检恢复帧。
4. 定位航向角高频波动的主要原因并实施针对性优化。
5. 建立固定的“初始问题bag—最新优化bag”评价方式，便于后续持续更新。

## 3. 评价指标与方法

本文使用的百分位统计量定义如下：

- **P95（第95百分位数）**：将全部样本从小到大排列，95%的样本不超过该数值，剩余5%的样本大于该数值。P95用于反映绝大多数帧的误差或波动上界，比最大值更不容易受单个极端样本影响。
- **P99（第99百分位数）**：99%的样本不超过该数值，剩余1%的样本更大，用于观察更靠近极端情况的波动水平。
- P95和P99不是最大值，也不是统计学中的95%或99%置信区间。最大值在表格中单独统计。
- 对位置误差和帧间变化，P95/P99均基于绝对值或非负距离计算。例如最新bag的 `abs(Δyaw)` P95为 `0.609°`，表示95%的连续相邻结果角度变化不超过 `0.609°`，约5%的变化大于该值。
- **RMSE（Root Mean Square Error，均方根误差）**：先计算每一帧识别值与真值的误差，对误差平方求平均后再开平方：

  ```text
  RMSE = sqrt((e₁² + e₂² + ... + eₙ²) / n)
  ```

  RMSE与原误差单位相同，数值越小表示整体精度越高。由于误差先平方，较大的误差会获得更高权重，因此RMSE对少量大误差比平均绝对误差更敏感。x、y和yaw分别计算各自RMSE；二维中心RMSE按 `sqrt(mean(Δx² + Δy²))` 计算。yaw误差在平方前先进行角度环绕处理。RMSE不是最大误差，也不表示某一比例的样本范围。例如最新bag的二维中心RMSE为 `7.336 mm`，表示全部帧二维中心距离误差的均方根为 `7.336 mm`。
- **偏差（Bias，平均有符号误差）**：先计算每一帧“识别值减真值”，再对全部有符号误差求平均：

  ```text
  Bias = mean(识别值 - 真值)
  ```

  正偏差表示识别结果平均位于对应坐标轴的正方向，负偏差表示平均位于负方向。例如最新bag去除50 mm固定补偿后，x偏差为 `+2.890 mm`，表示识别中心的x平均比真值大 `2.890 mm`；y偏差为 `+6.222 mm`；yaw偏差为 `+0.077°`。yaw偏差在求平均前先进行角度环绕处理。正负误差可能相互抵消，因此偏差接近0只表示系统性偏移较小，不代表每一帧都准确，仍需结合RMSE、P95和最大误差评价随机波动。

### 3.1 识别结果连续性

使用消息头时间戳逐帧匹配 `/perception/capture/points` 和 `/hecbot_perception/storage_result`：

```text
帧级连续率 = 有同时间戳结果的输入帧数 / 输入帧总数
```

这里的“输入帧”是已经完成20帧滑动窗口预热并进入检测的 `/perception/capture/points`。原始 `/livox/lidar_front` 中服务未激活或窗口尚未填满的帧不属于识别失败，单独统计但不纳入帧级连续率分母。

统计内容包括：

- 输入帧数、结果帧数和无结果帧数。
- 漏检段数和最长连续漏检帧数。
- 是否存在一个输入时间戳对应多个结果。
- 漏检恢复后的首帧是否发生位置或角度跳变。

无结果帧通过分阶段日志继续定位：

```text
2D线段分割
  → 候选生成
  → 像素到点云映射
  → 平面和尺寸过滤
  → 长短边及标签线拟合
  → 精调条件和置信度
  → 结果输出
```

### 3.2 识别结果精度

仿真货架参考中心为：

```text
base_link坐标系：(0.000000, -1.350000, 90.000000°)
```

两份bag中的 `base_link → livox_frame_front` 均保持固定：

```text
translation = (0.445000, -0.245000) m
yaw = -2.361577°
```

将货架中心转换至识别结果所在的 `livox_frame_front` 后，评价真值为：

```text
x = -0.399090 m
y = -1.122398 m
yaw = 92.361577°
```

算法输出位置不是Gazebo模型原点，而是在检测中心上叠加了 `range_compenstion = 0.05 m`。输出中心的补偿关系为“检测中心沿输出x轴反向偏移50 mm”。因此精度评价时按每帧yaw反向去除该补偿：

```text
x_center = x_output + 0.05 × cos(yaw)
y_center = y_output + 0.05 × sin(yaw)
```

后续所有位置精度指标均使用去除50 mm固定补偿后的中心。原始输出仍用于连续性和实际输出跳变评价。

分别统计校正后x、y和yaw的平均偏差、MAE、RMSE、P95绝对误差及最大绝对误差，同时统计二维中心距离误差。

当前bag没有录制 `/gazebo/model_states`，因此绝对精度评价基于“录包期间货架保持在配置参考位姿”的条件。后续录包应加入 `/gazebo/model_states`，使用逐帧模型位姿作为真值。

### 3.3 识别结果跳变

仅对“结果时间戳相邻且对应输入帧也连续”的帧对计算：

```text
Δx = x(i) - x(i-1)
Δy = y(i) - y(i-1)
Δyaw = wrap(yaw(i) - yaw(i-1))
```

统计 `|Δx|`、`|Δy|`、平面位置变化和 `|Δyaw|` 的中位数、P95、P99及最大值，并计数：

- `|Δx|` 或 `|Δy|` 超过 `5 mm`、`10 mm`、`15 mm` 的次数。
- `|Δyaw|` 超过 `1°`、`1.5°`、`2°` 的次数。
- 跨漏检间隔后的首个结果变化。

报告暂将 `|Δx| > 10 mm`、`|Δy| > 10 mm` 或 `|Δyaw| > 1°` 标记为需要关注的跳变，最终验收阈值应由对接控制容差确定。

## 4. 问题分析

### 4.1 识别结果不连续

#### 问题现象

初始问题bag的386帧中间点云只输出363帧结果，存在23帧无结果，且分成8段，最长连续漏检6帧。长边RANSAC优化后的中间测试bag仍有8帧无结果，说明长边方向优化不能解决候选生成阶段的漏检。最新bag中706帧进入检测的点云均在日志中产生结果，算法连续率达到100%。bag缺少最后一帧结果消息是录包截止造成，不计为算法漏检。

#### 已确认原因

第一类漏检发生在参考候选构造和点云映射之间：参考垂直边位于中心右侧时，原始边和镜像边的左右顺序可能反转，导致每行像素遍历起点大于终点。日志表现为已经生成参考候选且存在边界对，但采样像素数和映射点数均为0。

第二类漏检发生在参考短线拟合。中间测试bag的8帧无结果均满足：

```text
DepthReference = 0
width_diagonal = 0
MidPixel = (-1,-1)
StrictHypotheses = 0
TotalHypotheses = 0
```

这些帧仍具有约53～56个平面点，目标短线聚类仍有38～42个点，短线弦长约为 `0.214～0.217 m`，并非传感器或聚类突然丢失目标。原逻辑在参考短线RANSAC得到内点后直接使用随机样本建立的原始模型系数。宽向证据点到短线的距离接近判定下限，小幅模型偏转即可使 `width_diagonal` 从6～9个骤降为0，进而使参考中心失效。

对4段漏检代表帧使用全部内点进行PCA重算，均能重新得到6～9个合格宽向证据点，确认主要问题是参考短线模型系数未优化。参考中心失效时，严格候选在46帧中能够独立给出结果，但另外8帧同时发生关键垂直边减少或对角线条件失败，最终两条候选链路同时失效而漏检。

参考短线RANSAC内点重新优化模型系数后，前一版729帧全部满足 `DepthReference=1`，`width_diagonal` 稳定在5～9个，参考中心失效和无结果帧均消失。最新Q2/Q98版本继续保持706帧算法结果全覆盖，说明标签中心算法调整没有重新引入漏检。

#### 尚需验证的风险

本次固定仿真场景已经实现逐帧输出，但仍需在不同距离、视角、遮挡和点云密度下验证：

- 参考短线内点数量下降时，优化后模型是否仍能稳定生成宽向证据。
- 严格候选与参考候选是否可能在同一极端视角下再次同时失效。
- 固定距离和比例阈值对实际货架尺寸误差及安装误差的适应性。
- 多个相似参考短线同时出现时，`proposal_mid.size()==1` 的唯一性条件是否稳定。

### 4.2 yaw高频波动

#### 问题现象

初始问题bag中相邻连续帧的 `|Δyaw|` 最大为 `2.342°`，有37次超过 `1.5°`、8次超过 `2°`。跳变发生在正常连续输出中，不是漏检恢复造成。

#### 已确认原因

最终yaw与长边拟合方向始终保持固定的 `90°` 关系，因此最终旋转矩阵没有引入额外跳变，yaw波动直接来自长边方向。

进行专项诊断：对投影长边点计算PCA方向，并与RANSAC方向比较。若投影点PCA方向稳定而RANSAC方向跳变，则问题来自模型系数求解，而不是货架或输入点云真实旋转。

专项诊断中，投影长边的点数、有效长度、厚度和PCA方向均稳定，但原RANSAC方向可在相邻帧间变化约 `2.38°`。原逻辑在RANSAC选出内点后直接使用随机样本建立的初始模型系数，没有使用全部内点重新估计最终方向。当长边点形成具有一定厚度的条带时，多个斜率略有差异的随机模型可能获得相近支持度，最终方向会在这些模型之间切换。

#### 残余波动的可能原因

最新bag的最大 `|Δyaw|` 为 `1.177°`，有3次超过 `1°`，没有超过 `1.5°` 的情况。剩余波动可能来自：

- RANSAC内点集合在相邻帧发生变化。
- 长边有效内点数下降或离群点比例上升。
- 投影长边的毫米级厚度和Livox非重复采样造成主方向小幅变化。
- 平面投影系数变化导致长边点分布发生轻微改变。
- 当前普通最小二乘方向估计对非均匀点密度仍有一定敏感性。

### 4.3 x方向位置跳变

#### 问题现象

初始问题bag中相邻连续帧最大 `|Δx|` 为 `21.910 mm`，26次超过 `10 mm`。参考短线优化后的上一版bag虽然P95降至 `8.777 mm`，但曾出现 `29.396 mm` 的孤立最大跳变。实施Q2/Q98标签中心后，最新bag的P95进一步降至 `6.851 mm`，最大值降至 `13.403 mm`，大于 `10 mm` 的帧对只剩6个，所有大于 `20 mm` 的跳变均已消失。最新最大 `|Δy|` 为 `1.456 mm`。

因此Q2/Q98方案已经解决标签RANSAC内点质心造成的厘米级异常中心，但最终输出仍有少量10～14 mm的x变化，需要继续分解短边修正量。

#### 已确认原因

输出x由标签中心、短边交点修正和50 mm方向补偿共同决定。长边方向记为 `h`，忽略z方向后可近似写为：

```text
x_output ≈ tag_center.x
           + 0.75 × (gap - 0.2475) × y_v.x   # 短边交点修正生效时
           + 0.05 × sin(h)                   # 50 mm方向补偿
```

上一版 `17-06-53.bag` 的最大跳变已确认由两个因素叠加：标签线RANSAC内点子集质心偏移，以及短边修正启停。标签点形成约 `21 mm` 厚的条带，RANSAC距离阈值为 `7.5 mm`；随机模型可能选择点带中的不同局部子集，点密度不均匀时，直接对该内点子集求质心会产生明显位置偏移。

最新代码使用优化后的标签直线重新筛选完整标签候选点，将有效点投影到直线主方向，并以2%和98%分位端点的中点作为 `tag_center`。最新日志与结果逐帧关联后得到：

- 日志共记录746次Q2/Q98中心计算，没有发生回退。
- 每次原始候选点337～482个，重新筛选点占比最低 `97.08%`、中位数 `98.93%`。
- Q2/Q98稳健跨度为 `0.206982～0.215004 m`，没有出现线段范围突然坍缩。
- 在bag中704个相邻结果帧对上，Q2/Q98中心的 `abs(Δx)` 中位数为 `0.048 mm`、P95为 `0.969 mm`、P99为 `1.427 mm`、最大仅 `1.695 mm`。

这证明标签中心源头已经稳定。对剩余最大跳变 `74.008→74.108 s` 分解后：

```text
最终 Δx                  = +13.403 mm
Q2/Q98标签中心 Δx        =  +0.200 mm
标签中心+50 mm补偿项 Δx =  +0.700 mm
短边修正项 Δx            = +12.702 mm
```

该帧对的短边修正前后都处于启用状态，并不是开关切换；沿长边方向的实际修正量由 `+5.316 mm` 变为 `-7.401 mm`。当前逻辑允许 `gap-0.2475` 在 `±10 mm` 范围内直接乘以0.75，因此修正量理论范围约为 `±7.5 mm`。即使修正始终启用，只要交点 `gap` 从期望值一侧跳到另一侧，相邻帧仍可能产生接近15 mm的变化。最新bag反算出的短边修正量实际范围为 `-7.468～+5.668 mm`，剩余6次大于10 mm的x跳变均主要由该修正量快速反向变化造成。

#### 为什么全内点优化后最大 `abs(Δx)` 反而增大

当前先后实施了两处全内点优化：精调阶段的长边直线优化主要改善方向及yaw；`couple_lidar()` 中的参考短线优化主要稳定 `DepthReference` 和候选生成。两者都没有优化最终 `tag_center` 所使用的标签线RANSAC内点选择，也没有消除短边修正的硬切换。参考短线优化会改变正视投影和候选区域，但精调点最终转回雷达坐标系，不能直接产生约30 mm的x平移。对比结果表明：

- 在实施Q2/Q98之前，从初始问题bag到 `17-06-53.bag`，`abs(Δx)`中位数由 `2.808 mm` 降至 `2.256 mm`，P95由 `10.669 mm` 降至 `8.777 mm`，超过10 mm的比例由 `7.34%` 降至 `3.16%`，整体分布实际改善。
- 当时与 `15-02-37.bag` 相比，P95由 `8.837 mm` 微降至 `8.777 mm`，超过10 mm比例由 `3.19%` 微降至 `3.16%`，同样没有系统性恶化。
- 当时仅增大了最大值：`15-02-37.bag` 统计408个连续帧对，`17-06-53.bag` 统计728个帧对，后者恰好出现一次标签内点子集严重偏斜并伴随短边修正切换的极端帧。
- 由于使用的是不同时间段、不同点云采样且样本数不同的bag，不能仅凭最大值证明全内点优化导致x变差。严格因果验证需要对同一个输入bag分别运行优化前、优化后的程序进行A/B回放。

此外，参考短线优化将连续率提升到100%，原先会漏检的帧现在也进入位置统计，极值指标比仅统计成功帧时更容易暴露异常。最新Q2/Q98结果进一步验证：全内点优化本身没有导致x变差；替换标签内点质心后，最大 `abs(Δx)` 已由 `29.396 mm` 降至 `13.403 mm`。当前剩余主要问题已经从标签中心切换转移为短边交点修正量的帧间摆动。

### 4.4 精度对比参考点不一致

#### 问题现象

直接将原始输出位置与Gazebo模型原点比较时，初始和最新bag的二维差异均约为 `44 mm`，其中y方向差异约为 `-43.6 mm`。该数值容易被误判为货架中心的系统误差。

#### 已确认原因

Gazebo真值表示货架模型原点，算法输出则在检测中心上叠加了 `range_compenstion = 0.05 m`。算法沿输出x轴反向偏移50 mm后发布结果，因此原始输出点和Gazebo模型原点不是同一物理参考点。

按照每帧yaw反向去除50 mm补偿后，初始问题bag的二维中心平均误差为 `7.896 mm`，最新bag为 `7.252 mm`。原先约 `44 mm` 的差异主要是参考点定义造成的固定偏移，不能作为算法中心误差。

#### 剩余误差的可能原因

去除固定补偿后仍有约 `7.3 mm` 的平均中心误差，可能来自：

- Gazebo模型原点与标签几何中心仍存在小的安装偏移。
- `base_link → livox_frame_front` 外参误差。
- 标签中心、短边修正量和拟合点集的随机变化。
- 当前bag没有逐帧记录Gazebo货架模型位姿，配置参考位姿与实际模型位姿可能存在小偏差。

## 5. 解决方案

本章与第4章的问题小节一一对应。已实施方案和后续方案分开说明。

### 5.1 提升识别结果连续性

已实施：

- 在参考候选构造源头统一左右边界语义，避免候选四点顺序反转。
- 增加分割、候选、映射、几何过滤、精调及结果输出的分阶段统计日志。
- 保留失败帧的关键条件，使无结果能够定位到具体处理阶段。
- 在参考短线RANSAC得到内点后，使用全部内点重新优化直线模型系数，并让宽向证据判断、角度判断和参考坐标变换使用优化后的系数。
- 使用Bag中的平面调试点离线复算，确认原漏检帧在优化模型下仍具有6～9个有效宽向证据。

后续方案：

- 在不同距离、视角、遮挡和实际货架数据上重复验证100%连续性。
- 保留严格候选与参考候选的分支统计，监控参考候选是否出现多解或失效。
- 为参考短线记录优化前后方向及宽向距离余量，避免后续参数调整再次引入临界抖动。

### 5.2 降低yaw高频波动

已实施：

- 保留RANSAC的离群点剔除能力，在得到内点后使用全部内点重新优化长边直线系数。
- 仅对激光长边启用系数优化，避免改变短边、标签线、TOF检测和跟踪器行为。
- 发布投影前后标签点、长边点和短边点，并增加长边方向、内点数和最终yaw日志。

后续方案：

- 对最新bag剩余三次超过 `1°` 的帧检查内点集合、内点数和PCA特征值。
- 若仍需进一步降低P95，可评估加权PCA、沿长边分桶等权或更稳健的内点重估计。
- 在空间拟合稳定之前不优先增加时序低通滤波，避免用延迟掩盖单帧模型问题。

### 5.3 降低x方向位置跳变

已实施：

- 标签线RANSAC得到内点后，使用全部内点重新优化直线系数。
- 使用优化后的模型在完整标签候选点中按 `7.5 mm` 垂直距离重新筛选，避免直接依赖原始随机模型的内点子集。
- 将筛选点投影到优化直线主方向，以2%和98%分位端点的中点作为 `tag_center`。
- 当直线系数无效或有效点不足时保留原内点质心回退，并增加候选数、筛选数、稳健跨度和中心位置日志。

实施效果：Q2/Q98中心 `abs(Δx)` 的P95为 `0.969 mm`、最大为 `1.695 mm`，746次计算无回退；最终输出最大 `abs(Δx)` 从上一版的 `29.396 mm` 降至 `13.403 mm`，大于20 mm的异常跳变已经消失。

后续方案：

- 增加短边交点 `gap`、修正前后中心、实际修正标量及分项贡献日志，避免仅记录“是否修正”。
- 优先稳定短边 `gap` 的空间估计，例如优化短边模型后重新筛选内点、检查短边覆盖范围和交点条件数，避免交点在相邻帧跨越期望距离两侧。
- 对短边修正量增加连续化约束，可采用降低0.75增益、修正量限幅、死区/迟滞或轻量时序滤波；不能只平滑门限开关，因为最新最大跳变发生在修正连续启用期间。
- 使用同一个bag对短边修正优化前后程序做A/B回放，要求不牺牲绝对精度和连续性，再评价P95及最大 `abs(Δx)`。

### 5.4 统一货架中心精度评价参考点

已实施：

- 明确Gazebo模型原点与算法输出参考点不同。
- 精度评价时根据每帧yaw反向去除 `range_compenstion = 0.05 m`，再与Gazebo模型原点比较。
- 保持算法原始输出不变，避免为了评价口径而改变业务所需的补偿点。

后续方案：

- 后续bag增加 `/gazebo/model_states`，记录每一帧货架模型真实位姿。
- 核对雷达外参、标签安装位置以及剩余约 `7.3 mm` 中心误差的来源。
- 若业务需要评价补偿后的对接参考点，应在Gazebo模型中建立对应真值点，而不是继续使用模型原点。
