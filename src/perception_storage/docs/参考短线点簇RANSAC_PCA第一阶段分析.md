## 4. 失败帧与关注帧分类

按照在线判据 `N_inlier < 10` 或 `inlier ratio < 0.8`，失败帧为0。

日志侧也确认：

- 744帧全部 `DepthReference=1`；
- 744帧全部产生识别结果；
- `width_diagonal` 分布为5点5帧、6点159帧、7点509帧、8点63帧、9点8帧；
- `with_line` 744帧全部为0。

虽然没有失败帧，仍可分出三类关注帧：

1. **单点横向离群**：第400、401帧，时间戳232.514、232.616 s。点数43，RANSAC内点42，内点率0.9767；RANSAC/PCA方向差0.1279°、中心差0.958 mm。影响很小。
2. **点带较厚**：第665、666帧，时间戳259.214、259.312 s。W/L达到0.0595，`λ1/λ2` 降至463.3，但全部点仍为RANSAC内点，未造成拟合分歧。
3. **覆盖/密度变化引起中心移动**：第312→313帧中心变化最大，为9.507 mm，但方向只变化0.283°，长度由214.005 mm变为209.545 mm。这不是直线失拟，而是点簇长度方向覆盖或密度重分布造成的质心变化。

## 6. 初步选择策略和阈值

当前bag只有正常正样本，不能据此直接确定最终生产拒绝阈值。以下阈值可先作为下一阶段的质量门限，保留了相对本次观测极值的余量：

| 指标 | 本次观测范围 | 建议初始门限 |
|---|---:|---:|
| N | 36～45 | `N >= 30` |
| L | 0.195～0.215 m | `0.18 <= L <= 0.24 m` |
| W/L | 0.022～0.0595 | `W/L <= 0.07` |
| `λ1/λ2` | 463～2013 | `λ1/λ2 >= 300` |
| RANSAC内点率 | 0.9767～1.0 | `inlier ratio >= 0.95` |
| RANSAC/PCA `Δyaw` | 0～0.1279° | `Δyaw <= 0.5°` |

候选选择建议：

1. 先应用上述几何质量门限；门限不满足的候选不作为参考短线。
2. 多候选均有效时，优先选择长度最接近0.21 m的候选。
3. 长度接近时，依次优先更高的RANSAC内点率、更低的W/L和更高的 `λ1/λ2`。
4. 最后才使用与上一帧中心、方向的连续性作为同分候选的裁决项，避免时序先验掩盖单帧几何错误。
5. 中心采用Q2/Q98端点中点；方向采用RANSAC剔除离群后、全部内点PCA优化的方向。

下一阶段需要补充真实失败、遮挡、斜视、距离变化和干扰直线数据，再检查上述门限的漏检率和误选率，之后才能固化为生产阈值。
