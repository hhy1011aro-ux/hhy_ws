```
  网关 → 业务模块：路由 + 鉴权
  业务模块 → 基座：日志 + TraceID 写入
  业务模块 → 数据层：读写
  数据层 → 业务模块：返回结果
  业务模块 → 客户端：响应
  客户端 → 用户：语音播报
```
